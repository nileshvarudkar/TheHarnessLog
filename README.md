# The Harness Log

A daily newsletter on prompt engineering and agent-harness engineering: three actionable moves, a paper of the day, dispatches from practitioners, a repo of the day, and further reading.

- `issues/NNN-YYYY-MM-DD.html`: one self-contained page per issue
- `index.html`: archive of all issues, newest first (rebuilt by `scripts/build_index.py`)

Issues are generated and committed daily by a scheduled task. The archive starts at issue 063 (Nov 1, 2026); earlier issues were published only to a single live page and aren't preserved here.

To view the archive as a website, enable GitHub Pages for this repo (Settings → Pages → Deploy from branch → `main` / root).
